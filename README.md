# Spanish Reader

A daily graded reader for learning Spanish. Each day introduces a short story built around 5–9 new words, followed by spaced-repetition review of earlier vocabulary.

- 154 stories covering ~1,150 high-frequency words
- Tap any word to see its meaning and hear it pronounced
- Leitner-style review in both directions (Spanish → English, English → Spanish)
- Add your own words; progress is stored locally in the browser

It is a single static page with no build step, served with GitHub Pages.
